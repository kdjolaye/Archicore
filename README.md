Archicore est une application de gestion d'audit et d'archivage développée avec Spring Boot 4 et Angular 21.
Le système intègre une API REST sécurisée par JWT (HttpOnly cookies) et un contrôle d'accès strict par rôles.
Il gère de bout en bout les dossiers clients, les missions d'audit, l'équipe et les documents liés.
